# Vendored skills

Project skills that match this app's stack: Next.js, React 19 and Tailwind, plus Playwright for browser checks.
To update, copy the skill folders from a newer upstream checkout over these ones.

| Skill | Source | What it does |
|---|---|---|
| `react-best-practices` | Vercel | React and Next.js performance rules for components, data fetching and bundle size. |
| `composition-patterns` | Vercel | React composition patterns such as compound components and context providers. |
| `react-view-transitions` | Vercel | Page and element animations with React's View Transition API. |
| `web-design-guidelines` | Vercel | Reviews UI code against the Web Interface Guidelines, including accessibility. |
| `frontend-design` | Anthropic | Aesthetic direction and typography for new or reshaped UI. |
| `webapp-testing` | Anthropic | Drives the running app with Playwright: behavior checks, screenshots, browser logs. |
